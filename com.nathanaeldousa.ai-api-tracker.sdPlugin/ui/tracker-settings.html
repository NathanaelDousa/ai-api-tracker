Each tile tracks one provider. Hold the key 0.8 s to cycle.
🔑 API Keys & Budgets
OpenAI
Stored locally — only sent to api.openai.com.
Monthly budget for remaining-balance display.
Requires an Admin key — create one at platform.openai.com/organization/api-keys (Role → Admin). A regular project key (sk-proj-…) will return a 403 error.
Claude (Anthropic)
Stored locally — only sent to api.anthropic.com.
Requires an Admin key (sk-ant-admin…) — console.anthropic.com → Settings → Admin keys. Only available on enterprise/team plans. Standard accounts will see "Admin key required" and auto-refresh stops.
Gemini (Google)
Full path to your GCP service account JSON key file.
Optional if already embedded in the SA JSON.
Optional. Your average cost per API call. When set, the tile shows estimated spend instead of request count. Divide a past bill total by the request count to estimate this value.
GCP Console → IAM → Service Accounts → Create → grant Monitoring Viewer → Keys → Add Key → JSON. Enable the Cloud Monitoring API on your project. By default shows request count — set Cost/request above to convert to an estimated spend.
DeepSeek
Shows remaining credit balance. CNY is auto-converted to USD.
Optional — leave blank to use your credit balance as the total.
